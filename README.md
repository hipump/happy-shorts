# 🎬 Happy Shorts (롱폼 -> 9:16 유튜브 쇼츠 자동 생성 파이프라인)

유튜브 롱폼 영상(또는 로컬 원본 영상)을 입력받아 **AI 하이라이트 구간 자동 분석**, **단어 싱크 애니메이션 자막**, **트렌디한 시각 효과(상단 훅 뱃지, 하단 프로그레스 바)**를 적용하여 100% 로컬 무료로 9:16 규격의 완성형 쇼츠를 제작하는 파이프라인입니다.

---

## ✨ 핵심 기능

1. **2가지 입력 소스 완벽 지원**
   - **유튜브 URL**: `yt-dlp` 기반 최고 화질/음질 자동 다운로드 (`https://www.youtube.com/watch?v=...`)
   - **로컬 영상 파일**: `.mp4`, `.mov`, `.mkv` 등 로컬 파일 경로 입력 시 즉시 처리
2. **AI 대본 기반 스마트 하이라이트 추출**
   - `faster-whisper`를 통한 밀리초 단위 단어 음성 인식 (STT)
   - 로컬 **Ollama (`EEVE-Korean-10.8B`, `llama3`, `qwen2.5` 등)**를 활용해 몰입도 높은 30~55초 구간 자동 선별
   - **자연스러운 문장 경계 스냅(Snapping) 알고리즘**: 말이 중간에 짤리지 않고 자연스럽게 시작/끝나도록 보정
2. **미리캔버스 & 캔바 & 알파컷 실전 그래픽 템플릿 엔진 탑재**
   단순한 텍스트 폰트/색상 변경이 아닌, **상업용 숏폼 템플릿의 레이아웃 구조와 후킹 요소**를 완전 구현:
   - **💻 인터넷창 / macOS 브라우저 창 (`browser_window`)**:
     다크 네이비 메쉬 데스크 배경 + 맥OS 윈도우 프레임(🔴🟡🟢 트래픽 라이트 + URL 바) + 3D 볼드 타이포그래피 + 하단 콘솔 자막 & 해시태그 칩스
   - **🚨 미리캔버스 뉴스 포털 & 긴급 속보형 (`news_portal`)**:
     Clean 화이트 포털 캔버스 + 레드 방송 헤더(`MIRI NEWS ● LIVE`) + 형광펜 2단 헤드라인 바 + 현장 자막 브리핑 덱 & 핵심 요약 불릿 카드
   - **✨ 캔바 & 알파컷 인포 매거진 (`neon_magazine`)**:
     다크 슬레이트 캔버스 + 네온 사이언 발광 보더 + `HOT 필수시청` 스티커 + 형광펜 마커 키네틱 자막 + 하단 3줄 핵심 요약 카드
   - **💡 캔바 모던 클린 (`minimal_edu`)**:
     모던 슬레이트 캔버스 + 프리텐다드 서체 자막 + 깔끔한 1분 지식 노트 카드
   - **👤 9:16 인물 추적 풀스크린 (`interview_talk`)**:
     OpenCV/YuNet 안면 인식 기반 화자 자동 추적 9:16 크롭 + 키네틱 팝업 자막
   - **🎞 순정 원본 보존 (`source_pure`)**:
     영상 내 자체 자막/UI가 이미 있는 영상을 위해 추가 자막 간섭 없이 상단 헤드라인만 깔끔하게 노출
3. **바이럴 후킹(Hooking) 타이포그래피 & 폰트 이펙트**
   - **형광펜 마커 테이프 (`draw_marker`)**: 핵심 키워드 뒤에 반투명 비비드 형광펜 바(#FFE600, #00FFA3) 배치
   - **3D 익스트루전 & 더블 스트로크 (`draw_3d_text`)**: 두꺼운 블랙 외곽선(8~9px) + 입체 드롭 섀도우로 모든 배경에서 100% 시인성 보장
   - **2단 구조 헤드라인**: 1단(상황/맥락) + 2단(강렬한 후킹 펀치라인)으로 시선 즉각 집중
   - **실제 그래픽 칩 & 스티커**: 텍스트 폰트 깨짐 없는 깔끔한 벡터 배지와 뱃지 칩
4. **AI 대본 기반 스마트 하이라이트 & 단어 싱크 자막**
   - `faster-whisper` 밀리초 단위 단어 음성 인식 (기본: `large-v3-turbo`, STT 캐싱 지원)
   - 로컬 **Ollama (`qwen2.5:14b`, `EEVE-Korean` 등)** 기반 몰입도 높은 구간 자동 선정
   - EBU R128 (-14 LUFS) 표준 모바일 오디오 노멀라이제이션

## 🚀 빠른 시작 가이드

### 1) 🌐 웹 GUI 대시보드 (추천: 브라우저에서 편리하게 사용)
브라우저에서 유튜브 미리보기, 템플릿 카드 선택, OpusClip 스타일 AI 바이럴 점수 및 구간 트림, 스마트폰 쇼츠 뷰어로 시청하고 싶다면:
```bash
./run_web.sh
```
실행 시 자동으로 웹 브라우저(`http://localhost:3000`)가 열립니다.

### 2) 💻 터미널 대화형 마법사 (CLI 모드)
터미널에서 질의응답 형태로 빠르게 실행하고 싶다면:
```bash
./run.sh
```

### 🧭 대화형 실행 흐름 (5단계 마법사)
1. **스텝 1/5. 입력 소스 선택**:
   - `🌐 1) 유튜브 영상 URL (자동 다운로드)` / `⚡ 2) 최근 작업했던 영상 재사용 (캐시 즉시 적용)` / `📁 3) 로컬 영상 파일 (.mp4, .mov)`
2. **스텝 2/5. 생성할 쇼츠 개수**:
   - `1개 (추천)`, `2개`, `3개`, `직접 입력`
3. **스텝 3/5. 쇼츠 디자인 템플릿 선택**:
   - `💻 1) 인터넷창 / macOS 브라우저 창 썸네일형 (트래픽라이트 + 3D 폰트 + 해시태그)`
   - `🚨 2) 미리캔버스 뉴스 포털 & 긴급 속보형 (클린 화이트 + 방송 레드 헤더 + 형광펜 헤드라인)`
   - `✨ 3) 캔바 & 알파컷 인포 매거진 템플릿 (다크 슬레이트 + 네온 사이언 보더 + 요약 카드)`
   - `💡 4) 캔바 모던 클린 템플릿 (모던 슬레이트 + 프리텐다드 서체 자막)`
   - `👤 5) 9:16 인물 추적 풀스크린 (호르모지 스타일)`
   - `🎞 6) 순정 원본 보존 템플릿 (원본 화면 100% 보존, 자막 미생성)`
   - `🎨 7) 세부 맞춤 설정 (레이아웃 직접 지정)`
4. **스텝 4/5. 자막(캡션) 생성 여부 및 스타일 선택**:
   - `🔥 1) 바이럴 키네틱 팝 자막 (단어별 형광펜 하이라이트 + 볼드 외곽선 / 추천)`
   - `💬 2) 클린 미니멀 자막 (깔끔하고 단정한 프리텐다드 자막)`
   - `🚫 3) 자막 생성 안 함 (영상 원본 자체 자막 유지 또는 자막 없이 생성)`
5. **스텝 5/5. 쇼츠 목표 길이 선택**:
   - `⏱ 1) 30초 ~ 50초 (유튜브 쇼츠 표준 추천)`
   - `⚡ 2) 20초 ~ 35초 (짧고 빠른 템포)`
   - `📖 3) 45초 ~ 60초 (풍부한 스토리 완결형)`

## 🛠️ CLI 직접 실행 모드 (고급 사용자용)

스크립트나 자동화 파이프라인에서 인자를 직접 넘겨 실행할 수도 있습니다:

```bash
# 유튜브 URL로 즉시 생성
./run.sh "https://www.youtube.com/watch?v=유튜브영상ID"

# 로컬 파일로 즉시 생성
./run.sh "/path/to/my_video.mp4"

# 옵션 지정 실행 예시 (얼굴 추적 스마트 크롭 + 3개 클립)
./run.sh "https://www.youtube.com/watch?v=XXXXX" --clips 3 --layout smart_crop
```

## ⚙️ CLI 명령어 옵션 안내

| 옵션 | 단축키 | 기본값 | 설명 |
| :--- | :---: | :---: | :--- |
| `source` | - | *(필수)* | 유튜브 영상 URL 또는 로컬 비디오 파일 경로 |
| `--clips` | `-c` | `1` | 생성할 하이라이트 쇼츠 개수 (1개 이상) |
| `--template` | `-t` | `browser_window` | 디자인 템플릿 (`browser_window`, `news_portal`, `neon_magazine`, `minimal_edu`, `interview_talk`, `source_pure`) |
| `--layout` | `-l` | None | 레이아웃 수동 오버라이드 (`smart_crop`, `blur_background`, `studio_card`) |
| `--whisper` | `-w` | `large-v3-turbo` | 음성인식 모델 크기 (`base`, `small`, `medium`, `large-v3-turbo`) |
| `--llm` | `-m` | `qwen2.5:14b` | 하이라이트 분석에 사용할 Ollama 로컬 모델 |
| `--min-dur` | - | `30` | 하이라이트 최소 길이 (초) |
| `--max-dur` | - | `55` | 하이라이트 최대 길이 (초) |
| `--no-subtitles` | - | `False` | 자막(캡션) 생성 끄기 |
| `--no-badge` | - | `False` | 상단 훅 타이틀 뱃지 끄기 |

```
happy-shorts/
├── main.py                 # 실행 CLI 진입점
├── requirements.txt        # 의존성 패키지 목록
├── assets/
│   ├── fonts/             # Black Han Sans, Pretendard 폰트
│   └── models/            # OpenCV 얼굴 검출 캐스케이드 모델
├── src/
│   ├── models.py          # Pydantic 데이터 모델
│   ├── downloader.py      # yt-dlp & 로컬 파일 검증 모듈
│   ├── transcriber.py     # faster-whisper STT & 캐싱 모듈
│   ├── highlighter.py     # Ollama AI 하이라이트 분석 모듈
│   ├── framing.py         # 9:16 리프레임 & 얼굴 추적 모듈
│   ├── effects.py         # 단어별 팝업 자막, 뱃지, 프로그레스 바 모듈
│   ├── renderer.py        # FFmpeg 쇼츠 최종 렌더러
│   └── pipeline.py        # 전체 프로세스 통합 오케스트레이터
├── downloads/              # 다운로드된 유튜브 영상 저장소
├── cache/                  # 음성 자막 캐시 (재실행 시 고속 스킵)
└── output/                 # 완성된 9:16 쇼츠 MP4 결과물
```
