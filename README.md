# 🎬 Happy Shorts (롱폼 -> 9:16 유튜브 쇼츠 자동 생성 파이프라인)

유튜브 롱폼 영상(또는 로컬 원본 영상)을 입력받아 **AI 하이라이트 구간 자동 분석**, **단어 싱크 애니메이션 자막**, **트렌디한 시각 효과(상단 훅 뱃지, 하단 프로그레스 바)**를 적용하여 100% 로컬 무료로 9:16 규격의 완성형 쇼츠를 제작하는 파이프라인입니다.

---

## ✨ 핵심 기능

1. **2가지 입력 소스 완벽 지원**
   - **유튜브 URL**: `yt-dlp` 기반 최고 화질/음질 자동 다운로드 (`https://www.youtube.com/watch?v=...`)
   - **로컬 영상 파일**: `.mp4`, `.mov`, `.mkv` 등 로컬 파일 경로 입력 시 즉시 처리
2. **AI 대본 기반 스마트 하이라이트 추출**
   - `faster-whisper`를 통한 밀리초 단위 단어 음성 인식 (STT)
   - 로컬 **Ollama (`EEVE-Korean-10.8B`, `llama3`, `qwen2.5` 등)**를 활용해 몰입도 높은 30~55초 구간 자동 선별
   - **자연스러운 문장 경계 스냅(Snapping) 알고리즘**: 말이 중간에 짤리지 않고 자연스럽게 시작/끝나도록 보정
3. **트렌디한 숏폼 스타일 팝업 자막**
   - 모바일 최적화 굵은 폰트 (`Black Han Sans` / `Pretendard`)
   - 화자가 말하는 순간 해당 단어가 통통 튀며 **비비드 옐로우(#FFE600)**로 켜지는 **카라오케/바운스 애니메이션**
   - 두꺼운 블랙 외곽선(Stroke) & 드롭 섀도우로 모든 배경에서 높은 가독성 유지
4. **시청 지속 시간(Retention) 극대화 시각 효과**
   - **9:16 리프레임 레이아웃**:
     - `blur_background` (기본값): 상하단 몽환적 블러 + 중앙 원본 배치 (쇼츠 표준 스타일)
     - `smart_crop`: OpenCV 얼굴 인식 기반 화자 중앙 자동 추적 크롭
     - `center_crop`: 단순 9:16 중앙 크롭
   - **상단 훅(Hook) 타이틀 뱃지**: AI가 도출한 시선 강탈 헤드라인 캡슐 배너 (예: `🔥 핵심 요약`, `💡 10초 만에 끝내는 법`)
   - **하단 다이내믹 프로그레스 바**: 영상 길이에 맞춰 부드럽게 채워지는 시각 인디케이터
   - **오디오 노멀라이제이션**: 모바일 시청 환경에 맞춘 EBU R128 (-14 LUFS) 표준 음량 보정

## 🚀 빠른 시작 가이드 (대화형 마법사)

복잡한 옵션을 외울 필요 없이, 터미널에서 **`./run.sh`** 명령어 한 줄만 입력하면 친절한 대화형 보기 화면이 실행됩니다:

```bash
./run.sh
```

### 🧭 대화형 실행 흐름 (4단계)
1. **스텝 1/4. 입력 소스 선택**:
   - `🌐 1) 유튜브 영상 URL (자동 다운로드)` 또는 `📁 2) 내 PC의 로컬 영상 파일 (.mp4, .mov)`
   - 터미널로 영상 파일을 드래그앤드롭하거나 유튜브 URL 입력
2. **스텝 2/4. 생성할 쇼츠 개수**:
   - `1개 (추천)`, `2개`, `3개`, `직접 입력`
3. **스텝 3/4. 스타일 및 효과 옵션**:
   - `⚡ [빠른 추천] 기본 최적 옵션 (블러 배경 + 훅 뱃지 + 프로그레스 바 + 30~50초)`
   - `🎨 [맞춤 설정] 화면 레이아웃(블러/얼굴추적/중앙), 목표 길이, 뱃지/프로그레스 바 켜기/끄기`
4. **스텝 4/4. 실시간 진행 게이지 노출 & 자동 완성**:
   - 실시간 진행 상태와 % 게이지 바 노출
   - 생성 완료 후 Finder에서 결과물 폴더(`output`) 자동 열기 지원

## 🛠️ CLI 직접 실행 모드 (고급 사용자용)

스크립트나 자동화 파이프라인에서 인자를 직접 넘겨 실행할 수도 있습니다:

```bash
# 유튜브 URL로 즉시 생성
./run.sh "https://www.youtube.com/watch?v=유튜브영상ID"

# 로컬 파일로 즉시 생성
./run.sh "/path/to/my_video.mp4"

# 옵션 지정 실행 예시 (얼굴 추적 스마트 크롭 + 3개 클립)
./run.sh "https://www.youtube.com/watch?v=XXXXX" --clips 3 --layout smart_crop
```

## ⚙️ CLI 명령어 옵션 안내

| 옵션 | 단축키 | 기본값 | 설명 |
| :--- | :---: | :---: | :--- |
| `source` | - | *(필수)* | 유튜브 영상 URL 또는 로컬 비디오 파일 경로 |
| `--clips` | `-c` | `1` | 생성할 하이라이트 쇼츠 개수 (1개 이상) |
| `--layout` | `-l` | `blur_background` | 화면 비율 모드 (`blur_background`, `smart_crop`, `center_crop`) |
| `--whisper` | `-w` | `small` | 음성인식 모델 크기 (`base`, `small`, `medium`, `large-v3-turbo`) |
| `--llm` | `-m` | `qwen2.5:7b` | 하이라이트 분석에 사용할 Ollama 로컬 모델 |
| `--min-dur` | - | `30` | 하이라이트 최소 길이 (초) |
| `--max-dur` | - | `55` | 하이라이트 최대 길이 (초) |
| `--no-badge` | - | `False` | 상단 훅 타이틀 뱃지 끄기 |
| `--no-progress` | - | `False` | 하단 프로그레스 바 끄기 |

## 📁 디렉토리 구조

```
happy-shorts/
├── main.py                 # 실행 CLI 진입점
├── requirements.txt        # 의존성 패키지 목록
├── assets/
│   ├── fonts/             # Black Han Sans, Pretendard 폰트
│   └── models/            # OpenCV 얼굴 검출 캐스케이드 모델
├── src/
│   ├── models.py          # Pydantic 데이터 모델
│   ├── downloader.py      # yt-dlp & 로컬 파일 검증 모듈
│   ├── transcriber.py     # faster-whisper STT & 캐싱 모듈
│   ├── highlighter.py     # Ollama AI 하이라이트 분석 모듈
│   ├── framing.py         # 9:16 리프레임 & 얼굴 추적 모듈
│   ├── effects.py         # 단어별 팝업 자막, 뱃지, 프로그레스 바 모듈
│   ├── renderer.py        # FFmpeg 쇼츠 최종 렌더러
│   └── pipeline.py        # 전체 프로세스 통합 오케스트레이터
├── downloads/              # 다운로드된 유튜브 영상 저장소
├── cache/                  # 음성 자막 캐시 (재실행 시 고속 스킵)
└── output/                 # 완성된 9:16 쇼츠 MP4 결과물
```
